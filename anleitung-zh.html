1. 概览与入门步骤

My Whiskey Collection 是装在口袋里的个人威士忌收藏：您可以管理库存、存放位置、心愿单和统计数据。一切都在您的设备上运行；借助同步码，可以连接多台设备。

在底部（PC 和横屏 iPad 上：在左侧）有一个包含七个区域的栏：

区域用途
收藏所有威士忌、搜索、筛选、排序、添加威士忌、饮用
统计库存、价格、存放、饮用历史的分析
历史您已喝过的威士忌
酒架存放规划：存放和移动威士忌、二维码标签
心愿单您还想购买的威士忌
导入导出备份您的数据，读入表格和备份文件
设置名称、货币、语言、云端、定义酒架

最初的五个步骤

  1. 选择语言和货币：设置 → 通用。货币会自动跟随语言。
  2. 定义酒架（可选）：设置 → 酒架（参见第 5 节）。
  3. 添加您的第一款威士忌：在收藏中点按 +（第 2 节）。
  4. 存放它：为这款威士忌指定酒架中的一个位置。
  5. 备份：导入导出 → JSON 备份，或设置云端同步（第 11 节）。
设置中的各部分可以折叠。首次启动时“通用”是展开的，其余为折叠状态。应用会记住您上次展开或折叠的内容。

2. 添加威士忌

在收藏中点按 +。添加威士忌有多种方式，可以组合使用。

a) 手动输入

填写各字段：名称 / 酒厂、年份、瓶数、威士忌类型、产区（例如斯佩赛、艾莱岛、肯塔基）、国家、酒厂、年份（年）、ABV %、酒桶、存放位置、适饮温度、价格、评分、备注。只有名称是必填项。点按保存即可创建这款威士忌。

  • 年份：年份是该酒瓶的装瓶年份或蒸馏年份。陈年年数是熟成时间（年，例如 12），ABV 是酒精度（百分比），酒桶是桶的类型（例如雪莉桶、波本桶）。
  • 库存、最低和最高：如果您输入了最低值，库存低于该值时应用会发出提醒，并建议将这款威士忌加入心愿单（第 3 节）。
  • 自己的照片：“拍照 / 选择照片”可为威士忌附上一张照片。照片保存在此设备上，包含在 JSON 备份中，但不会同步到云端。

b) 扫描酒标（AI）

点按扫描酒标（AI）并拍摄酒瓶的酒标。AI 会读取名称、年份、类型、产区、国家、酒厂、陈年年数、ABV 和酒桶，并估算适饮温度。请检查这些值后再保存。首次使用前，应用会征求您的同意（第 12 节）。

c) 扫描条形码

点按扫描条形码，将酒瓶的条形码对准取景框。应用会在免费的商品数据库中查询该编号（免费，不消耗 AI 额度），如果找到，就会填入名称、生产商和威士忌类型。它会根据名称补全年份，或向您询问年份。

  • 如果这瓶酒已经在收藏中，应用会询问“再添加一瓶吗？”——当您又买了同样的酒时，这是增加数量的快捷方式。
  • 如果条形码不在数据库中（小型酒厂很常见），会出现带有扫描酒标（AI）按钮的提示。该编号仍会与威士忌一起保存，这样下次就能立即识别这瓶酒。

d) 查询威士忌（AI）

查询威士忌（AI）会让 AI 在网上搜索产区、国家、酒厂、陈年年数、ABV、酒桶、适饮温度、当前平均价格，以及（在网页版中）酒瓶图片。您已填写的字段不会被覆盖。输入名称和年份且尚无价格时，这也会自动执行。

iPhone 应用不会从互联网加载酒瓶图片（App Store 规定）。您可以改为拍摄自己的照片。

3. 收藏

搜索、筛选、排序

  • 顶部的搜索：按名称、产区、国家和酒厂查找威士忌。
  • 筛选：全部、Single Malt、Bourbon / Rye、Blended、World、其他。点按某个类型时，搜索内容会自动清除。
  • 排序：最新添加、名称、年份、酒厂、产区或国家。
  • 列表 / 卡片：列表按钮可在紧凑列表和详细卡片之间切换。

威士忌卡片

卡片显示名称、年份、酒厂、评分（星级）、产区和国家（点按可打开地图或该国的威士忌产区地图）、瓶数、适饮温度（🌡）以及存放位置（点按可跳转到酒架）。小小的平底杯图标会打开该酒厂的维基百科页面。

卡片底部有：编辑、饮用和 🗑（删除威士忌）。

库存、最低/最高与购物清单

如果您为某款威士忌输入最低值（也可选择输入最高值），卡片会显示“库存 · 最低 · 最高”，低于该值时以 ⚠ 提醒。补货按钮会打开购物清单：列出所有低于最低值的威士忌（目标为最高值，否则为最低值）。您可以分享或复制该清单，也可以将这些威士忌加入心愿单。

4. 饮用威士忌

在威士忌卡片上点按饮用，会打开喝威士忌对话框：

  • 从哪个位置取出？——选择酒瓶取自的酒架位置，或选择“酒瓶不在任何位置”。该位置随即空出。
  • 和谁一起喝的？——您的客人姓名（可选）。
  • 场合——春天、夏天、秋天、冬天、生日、派对或“随心小酌”（可多选）。

饮用会减少一瓶，并在历史中创建一条记录。彩带和音效会为此庆祝（可在设置中关闭）。如果这是最后一瓶，应用会告知您：这款威士忌随后会从收藏中消失（但仍保留在历史中）。

威士忌最好在约 16–20 °C 下纯饮；应用会将这一估计值显示为适饮温度。

扫描快速饮用：收藏中的圆形 🥃 按钮会拍摄酒标，在您的收藏中识别出这款威士忌，并立即打开“饮用”对话框。

5. 酒架与存放

定义和编辑酒架

设置 → 酒架（点按标题展开）：输入名称、层数、每层位置数和每个位置的瓶数，然后点按 ＋。“瓶/位”对于瓶架为 1，对于地面或木箱则更大。在列表中，每个酒架都有：

  • 用于更改顺序的拖动柄 ⠿，以及列表下方的按 A–Z 排序按钮，
  • ▦ 用于二维码标签，✏️ 用于编辑，🧹 用于清空，🗑 用于删除。

通过编辑（✏️），您可以重命名酒架、更改每层的位置数、在上方或下方添加层、删除层，并为每一层指定独立的名称和瓶数。因此失去位置的酒瓶之后会被视为“未入库”；威士忌本身仍保留在收藏中。进行此类更改前，应用会先询问。

“酒架”区域

在顶部，您通过磁贴（名称和“已占用 / 位置数”）选择酒架。顺序也可以在这里更改：在 PC 上拖动磁贴，在触摸屏上长按磁贴约半秒，然后拖动。下方是存放规划：每一层及其位置。已占用的位置会显示一个颜色与威士忌类型对应的酒瓶。

存放

  1. 在“未分配”下点按一款威士忌（该列表可按酒厂和国家筛选）——或在收藏中点按“未入库”提示。
  2. 点按一个空位。对于地面和木箱，应用会存入尽可能多的酒瓶。

扫描威士忌并存放会拍摄酒标、找到该威士忌，并引导您完成存放。

已占用的位置、移动、移除

点按已占用的位置：您会看到这款威士忌，并可以打开它、从位置移除或移动（然后点按一个空位）。清空酒架会取出酒架中的所有酒瓶（需确认）。

二维码标签与“扫描层”

通过二维码标签（设置 → 酒架 → ▦），您可以为酒架创建一张标签，并为每一层各创建一张。可作为 PDF 分享或打印（标签纸 63.5 × 38.1 mm，每页 21 张）并贴上。之后：在酒架区域使用扫描层——您会看到该层上有什么，并可以存放到这里、取出、饮用、移动酒瓶或整层移动。在“添加威士忌”表单中，扫描某一层的标签也会填入存放位置。

6. 历史

历史列出您喝过的所有威士忌，包括日期、威士忌、价值、客人和场合。您可以按威士忌类型和场合筛选，并编辑记录（客人、场合）。历史为统计中的“每月/每年饮用”、支出和饮用频率分析提供数据。

7. 心愿单

  • + 添加心愿：手动添加或通过扫描酒标添加，可附带可选备注（“在哪里购买？”）。
  • 搜索价格（💶）：应用会在网上搜索这款威士忌的价格，显示最便宜的结果并乘以数量。这些是不作保证的参考值——请向店家确认运费和库存情况。
  • 左侧的勾选框：标记为已购买/已完成（该行会变淡）。
  • → 收藏：将心愿移入收藏（带数量，如有则带最低价格），如果您有酒架，会直接进入存放流程。
  • 如果某款威士忌低于其最低值，应用会建议按缺少的数量将其加入心愿单（“补货”）。

8. 统计

从上到下：

  • 关键数据：瓶数、威士忌、总价值、平均评分。
  • 按类型和最佳威士忌（按评分或饮用频率，可按星级筛选）。
  • 按国家、产区、酒厂：条形图（最多 8 项，其余显示为“另外 n 项”）；点按会在收藏中搜索。按年份：柱状图，可横向滚动。
  • 价格：每瓶平均、最便宜、最贵、价格区间（按您的货币调整）以及各国价值。
  • 储存：占用百分比、空位、未入库的酒瓶，以及每个酒架一条的条形图（点按可跳转到该酒架）。
  • 饮用：按月（最近 12 个月）和按年，以及已饮酒瓶的支出。
  • 按平均评分得出的评分最高的国家和酒厂（收藏与历史合计）。
  • 补货：低于最低库存的威士忌（打开购物清单）、未完成的心愿及其价值。

没有数据的部分（例如没有价格时）会被隐藏。

功能用途
导出 CSV适用于 Excel 或 Numbers 的表格
导出 Excel.xlsx 文件
导出 PDF可打印的概览
JSON 备份完整的数据备份（威士忌、心愿单、历史、酒架、显示名称、自己的照片）

CSV 和 Excel 中的列为：名称、年份、类型、产区、国家、酒厂、陈年年数、ABV、酒桶、酒架、层、位、瓶数、评分、价格、备注。导入时也接受旧的列名。

请定期进行 JSON 备份。JSON 导入会用备份内容替换收藏（应用会先询问）。在新设备上，这样可以恢复所有内容。您也可以改用云端同步（第 11 节）。

10. 设置

通用

  • 显示名称（标题）：“Peter”会变成“Peter's Whiskey Collection”等。留空则使用默认标题。
  • 货币：€、$、£、CHF、A$、C$、SEK、NOK、DKK、PLN、HUF、CZK、RON、RUB、UAH、JPY、CNY、KRW、INR。
  • 语言：25 种语言变体，包括德语、英语、英语（美国）等。货币会自动更改（瑞典语 → 克朗，英语（美国）→ 美元 US $，英语（英国）→ £）。例如：切换到瑞典语时，应用会改为 SEK，并询问是否按今天的欧洲中央银行汇率换算所有价格（“确定”），还是只更改标注（“取消”）。RUB 和 UAH 没有汇率。您可以随时手动更改货币。
  • 饮用时的彩带与音效：两者都开、仅彩带或关闭。
  • 字体：可从十种字体中选择。
  • 温度单位：°C 或 °F（英语（美国）会自动设为 °F）。

存储

仅限此设备或云端（同步码，第 11 节）。

AI 额度（仅限 iPhone 应用）

显示剩余的 AI 扫描次数、设备 ID，并在需要时显示充值额度或解锁码。参见第 12 节。

威士忌数据库

  • 更新所有威士忌（AI）：为所有威士忌补全缺失的产区、国家、酒厂、陈年年数、ABV、酒桶、适饮温度和价格（网页版还包括酒瓶图片）。已有的值会保留。如果已存在适饮温度，应用会先询问是否也用 AI 的值替换它们。提示：请先导出一份 JSON 备份。

酒架

参见第 5 节。标题中会显示酒架的数量。

11. 同步两台设备

  1. 第一台设备：设置 → 存储 → 云端 → 创建新的同步码。同步码会显示在屏幕上；使用通过邮件保存同步码可以发送给自己。
  2. 第二台设备：设置 → 存储 → 云端 → 输入同步码（小写，无空格）→ 连接。如果该设备上已有威士忌，应用会询问是否将其与云端数据合并。
  3. 之后两台设备会自动同步（例如打开应用时）；立即同步可手动触发。规则是：以最新的更改为准。

威士忌、心愿单、历史、酒架以及语言、货币等设置都会同步。自己的照片和设备专属数据不会同步。任何知道您的同步码的人都能看到您的威士忌——请只与您信任的人分享。同时也请保留一份 JSON 备份。

12. AI、隐私与费用

  • AI 用于什么？扫描酒标、查询威士忌、搜索价格和“更新所有威士忌”。照片或威士忌名称会通过我们的服务器发送到 AI 服务（Anthropic，美国）进行分析——不含姓名或账户信息。首次使用前，应用会征求您的同意。
  • 扫描条形码只会将编号发送到免费的商品数据库，不消耗 AI 额度。
  • 费用（iPhone 应用）：每次安装包含 50 次 AI 调用，已含在购买价格中；更多次数可作为可选的一次性购买获得（不是订阅，额度不会过期）。应用中的其他一切功能均无额外费用。额度用完后，除 AI 功能外的所有功能仍可继续使用。
  • 数据：只要您不启用云端，一切都保留在您的设备上。无广告、无追踪、无用户账户。详情请见隐私政策（德语）。

13. 小贴士与常见问题

  • 在 iPad 或 PC 上，布局会自适应：栏更宽、多张卡片并排显示，在 PC（和横屏 iPad）上导航位于左侧。手机也可以横屏使用。在 PC 上，Esc 会关闭最上层的窗口；在手机上，向下滑动窗口即可关闭。
  • 我的威士忌不见了：请参见支持——可通过同步码或 JSON 备份恢复。
  • 某款威士忌的条形码没有匹配结果：小型酒厂很常见。请使用酒标扫描。
  • AI 读错了：请手动更正字段并保存；AI 给出的值只是建议。
  • 应该让威士忌在瓶中“陈年”吗？不需要。威士忌只在桶中熟成，而不是在瓶中——无论开封与否，酒瓶都不会随岁月变得更好。因此没有适饮期功能；适饮温度（纯饮，约 16–20 °C）只是一个参考。
  • 页面仍显示旧版本（网页）：请刷新页面（在 PC 上按 Ctrl+F5）。
